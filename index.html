Platapus Pathing

A path-following library for FTC robots. It combines time-consistent motion profiling with aggressive on-path correction, and adds sensor fusion and online self-tuning.

View on GitHub
  • Hybrid follower. Each update reads the motion profile, resolves path geometry, applies feedforward, then adds PID correction. Wheel powers are scaled rather than clipped, so direction stays correct at full speed.
  • Error-scaled correction. Correction strength grows smoothly with tracking error, with no threshold to chatter around.authority = 1 + (A − 1) · clamp(error / scale, 0, 1)
  • EKF pose fusion. An extended Kalman filter blends odometry and IMU into one pose estimate, with an interface ready for vision.
  • Online feedforward tuning. Fits u = kS·sign(v) + kV·v + kA·a by recursive least squares while the robot drives, and saves the gains between runs.
  • Stall detection. Compares each motor's current against the model's prediction at the commanded velocity, so a jammed wheel is caught.
  • Tested core. Pure-Java core with 274 headless unit tests, plus a collision planner for alliance paths using the separating axis theorem. It has not run on a robot yet; hardware bring-up is the next step.

DECODE robot software

Software for team #28888's 2025–26 robot: a mecanum drive with a two-stage intake, a flywheel shooter and a rotating turret.

View code on GitHub
  • Field-locked turret. Uses goBILDA Pinpoint odometry to compute the angle to the goal every loop (the demo above). PD control with static-friction feedforward and encoder soft limits.
  • Vision aiming. AprilTag tracking with manual camera exposure and gain to cut motion blur while the robot moves.
  • Autonomous routines. State-machine autos on Pedro Pathing that drive, intake and score several cycles in 30 seconds.
  • Shooter control. Closed-loop flywheel velocity (PIDF) with switchable shot speeds. Bulk sensor reads keep the loop fast, and touch sensors make the controller rumble when a game piece is loaded.

Independent reinforcement learning research

A deep RL agent for a complex, long-horizon task in a 3D simulated environment, built without an off-the-shelf research framework.

  • Custom environment interface. A Java server streams simulation state over sockets to a Python trainer.
  • Long horizons. Symbolic observations and a discretised action space keep the task learnable.
  • Training method. Curriculum-based rewards, hierarchical skill composition, and imitation learning to bootstrap early behaviour.
